# Chess core acceptance — до реализации

Источники: ТЗ v0.3 §§7,10 (AC-01,02,10), roadmap R0.2, текущая задача.
Область: только браузерное ядро; тренировка — placeholder. Без сервера и базы.

Все сценарии ниже PLANNED до запуска. Oracle: правила шахмат и инварианты ТЗ,
а не копия алгоритма реализации. Изоляция: синтетические FEN, новая партия в каждом
unit-тесте; локальный Vite и новый browser context в E2E; без внешних сервисов.

Команды после подготовки frontend: `npm run typecheck`, `npm test`, `npm run build`,
`npm run lint`, `npm run test:e2e` из frontend. Browser prerequisite: Chromium Playwright.
Побочные эффекты: node_modules, dist, test-results (игнорируются Git).
Impl handoff: реализовать C01–C11. Review handoff: проверить оракулы, preview invariants,
