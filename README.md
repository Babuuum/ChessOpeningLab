# ChessOpening Lab — Chess Core MVP

Браузерное исследование позиций на React, TypeScript, Vite, chess.js и react-chessboard.
Node.js 22.12+ (проверяемая среда: 22.23.1), npm 10+.

```bash
cd frontend
npm install
npm run dev
```

Открыть http://127.0.0.1:5173. Для воспроизводимой установки из включённого `package-lock.json` использовать `npm ci`.

```bash
cd frontend
npm run typecheck
npm test
npm run lint
npm run build
npx playwright install chrome
npm run test:e2e
```

Playwright использует Google Chrome (channel `chrome`), мобильные сценарии — эмуляцию Chromium. Если Chrome уже установлен, команду установки браузера пропустить. Playwright сам запускает Vite. Для проверки на физическом телефоне в доверенной
локальной сети: `npm run dev -- --host 0.0.0.0`, затем открыть IP компьютера:5173.

## CI

`Frontend CI` проверяет push и PR в `main`, также доступен ручной запуск
`workflow_dispatch`. Ubuntu 24.04, Node.js 22; `npm ci`, typecheck, lint, unit,
build и Playwright Chrome с системными библиотеками. При сбое сохраняется
`playwright-failure` на 7 дней. Один mobile mouse-drag skip ожидаем; mouse проверяется
на desktop. Секреты и переменные окружения для приложения не требуются;
workflow устанавливает `CI=true`. Deployment отсутствует.

Локально повторить команды выше; браузер с системными библиотеками установить
через `npx playwright install --with-deps chrome`. Для повторения параметров CI:
`npm run test:e2e -- --forbid-only --workers=1 --reporter=line,html`.
Результаты проверок, разбор advisories, проверка на GitHub и handoff REL-03:
[REL-02 CI report](docs/REL-02_CI_REPORT.md). Реальный Actions run пока NOT_RUN.

## Поведение

На главной выбрать «Исследовать». Клик/касание фигуры показывает маркеры,
клик/касание назначения выполняет ход. Также доступно перетаскивание.
Играть можно за обе стороны по очереди. «Ваша сторона» задаёт ориентацию и цвета
подсветки; смена стороны начинает новую партию.

Союзные ходы: синие точки; чужие: красные кресты. Взятия: кольца с разной
обводкой. Если сейчас очередь другой стороны, это только условный preview на копии
позиции с очищенным en passant, а не прогноз следующего хода или карта атак.
Выбор фигуры не изменяет FEN/очередь/историю. Превращение требует выбора q/r/b/n.
Навигация сохраняет будущее до первого нового легального хода, который создаёт ветку.

## Ручная проверка

1. Выбрать e7 в начальной позиции: красные маркеры, FEN не меняется; e7-e5 запрещён.
2. e2-e4, e7-e5, g1-f3; назад/вперёд; из прошлого сыграть другое продолжение.
3. Сменить сторону: доска развёрнута, история пуста; союзные чёрные — синие.
4. Рокировка: e4 e5 Nf3 Nc6 Bc4 Nf6, затем e1-g1.
5. En passant: после рестарта e4 a6 e5 d5, затем e5-d6.
6. Превращение: a4 h5 a5 h4 a6 h3 axb7 hxg2 bxa8 (выбор фигуры); повторить для четырёх вариантов.
7. Мат: f3 e5 g4 Qh4. Проверить статус.
8. На узком экране/телефоне повторить кликами/касаниями; проверить историю и режим «Тренировать».

## Структура и границы

`frontend/src/chess/core.ts` — чистый state/правила, без React. `App.tsx` — UI.
Контракт и заранее определённые сценарии: `docs/CHESS_CORE_ACCEPTANCE.md`.

Тренировка — явно обозначенный placeholder. Нет каталога дебютов, сервера,
компьютерных ответов, оценки движка, сохранения после перезагрузки или аккаунтов.
В данных нет вымышленных оценок/статистики. Preview невозможной очереди не обещает
будущую легальность. Длинная история пересчитывается с начальной позиции; для
дебютного MVP это приемлемо. Перезагрузка страницы сбрасывает партию.
